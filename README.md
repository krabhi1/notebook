# 📓 Notebook

A unified workspace for technical documentation, diagrams, and interactive code editing. Built for developers who need a centralized hub for their ideas.

## ✨ Features

- **Mermaid Diagrams**: Generate flowcharts, sequences, and architecture maps via code.
- **Advanced Code Editor**: Integrated Monaco editor with syntax highlighting and intelligent features.
- **Smart Organization**: Manage your workspace with nested folders and intuitive navigation.
- **Edge-Powered Sync**: Secure storage and instant sharing powered by Cloudflare D1.

## 🏗️ Roadmap

- **Real-time Collaboration**: Simultaneous multi-user editing.
- **Excalidraw**: Integrated virtual whiteboarding for sketches.
- **Design Tools**: Color palette generator (shades & gradients).
- **Live Web Editor**: Rapid prototyping with Tailwind CSS and real-time preview.
- **Engineering Tools**: Logic gate simulator and SQL diagram builder.

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Initialize database
pnpm run db:migrate

# Start development server
pnpm run dev
```

## 🛠️ Tech Stack

- **Frontend**: React 19, TanStack Start, Tailwind CSS 4
- **Backend**: Cloudflare Workers & D1 (SQLite)
- **ORM**: Drizzle ORM
- **Tooling**: Biome, Vitest, Vite
